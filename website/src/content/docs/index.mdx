## What it does

Write a spec, break it into tickets, and Harmonic works through them. For
each ticket it runs a coding agent to implement the change, has an AI critic
review the result, and merges the branch and closes the ticket once it
passes. You watch a board and step in only when a ticket needs a human.

Harmonic is designed to run alongside
[Matt Pocock's Skills](/harmonic/start/spec-driven-development/), which turn
your spec into labelled tickets in your tracker. The ones labelled for an
agent, Harmonic runs itself: it hands the agent the command the ticket
calls for, `/implement` and the rest of the Skills, and lets them do the
work exactly as if you'd typed it. If the agent stalls on a
question it can't answer, it hands the ticket back to you.

## The rest of it

- **No lock-in.** Harmonic drives every agent over [ACP](https://agentclientprotocol.com),
  so Claude Code, Codex, Copilot, and OpenCode are interchangeable.
- **Ad-hoc work too.** You can queue a one-off task by hand instead of from
  the tracker. Those add a human review gate: you accept or reject before
  anything merges.
- **Glanceable.** One board per repo, readable from a side monitor, with live
  token usage and cost on every attempt.

## Get started

```sh
npm install -g @mintopia/harmonic
harmonic start
```

Open `http://localhost:4700`, then follow the
[Quickstart](/harmonic/start/quickstart/) to connect a tracker and run
your first ticket.
