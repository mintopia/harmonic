## What Harmonic is

Harmonic queues, runs, and reviews autonomous coding-agent Tasks. It drives
agent harnesses — Claude Code, Codex, Copilot — over
[ACP](https://agentclientprotocol.com) from one board: agents run
unattended, and nothing merges without passing the review gate.

## The trustworthy-autonomy promise

Success for Harmonic is **trustworthy autonomy**: agents run unattended,
the operator gets notified, reviews the result, and accepts or rejects it —
nothing lands without passing that review gate. The operator rarely has to
babysit a run; they set tasks up, get notified, review, and accept.

## Get started

```sh
npm install -g @mintopia/harmonic
harmonic start
```

Then open `http://localhost:4700`. See [Getting started](/harmonic/using-harmonic/getting-started/)
for the full walkthrough.
