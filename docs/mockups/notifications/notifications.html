C · Toast with auto-dismiss indicator

Timing. A toast is how a Notification first appears. Success/info auto-dismiss after 6s, errors after 12s. A 3px bar along the bottom edge drains left to right in the toast's own colour (looping here so you can watch; in the app it plays once). Hover or keyboard focus pauses the timer and the bar (try it); ✕ always stays and dismisses immediately. Reduced-motion users get a static bar. Local request errors use the same toast but are never stored here.
