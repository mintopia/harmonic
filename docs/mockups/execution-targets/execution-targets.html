Confirmation · the consequence comes before the button

Rotate the signing key for k8s-prod?

Running pods lose git access. Rotating the key revokes every outstanding pass.
  • 2 Tickets are running on k8s-prod now. Their next checkpoint push fails until they start a new pod.
  • New pods get a pass signed with the new key at start, so waiting Tickets are not affected.
  • Update the key on the Repository Proxy too. Until you do, the proxy rejects every pass from Harmonic, new ones included.

The new key is shown once, for you to copy to the proxy. Harmonic stores it as a Secret and never shows it again.
