Which agent and model?

Picks the Harness and model for the workflow’s agent steps. A step that names its own harness or model in YAML keeps it. First match wins.

3 · Route Classifier

Reads an unlabelled Ticket and picks one Model Option below. It never picks outside the list. The Workflow classifier in step 1 uses this backend too.

Model Options

The closed list the classifier and Routing Labels pick from. Write each description as when it fits. Workflow YAML can reference a code.

CodeHarness · modelWhen it fits
deepClaude · opus-5-5Cross-cutting changes, unclear specs, concurrency or schema work.
standardClaude · sonnet-5-5Most feature and bug work with a clear spec.
fastClaude · haiku-5-5Docs, copy, renames, dependency bumps.
second-opinionCodex · gpt-5-codexA Retry after a Claude Attempt failed twice.

4 · Default agent

Used when no label matches and the classifier is off or abstains. Harness settings live in Integrations › Harnesses.
